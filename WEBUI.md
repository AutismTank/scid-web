# Scid Web

A modern web interface for Scid vs. PC.

## Goal

Scid Web aims to provide a modern browser-based interface while
retaining the chess database functionality of Scid vs. PC.

## Planned architecture

Browser
    ↓
Web API
    ↓
Scid core
    ↓
Scid databases

## Development

Phase 1:
- Fork Scid vs. PC
- Build Scid on the VPS
- Establish the development environment

Phase 2:
- Create the first web API

Phase 3:
- Create the web interface

Phase 4:
- Add chessboard and game viewer

Phase 5:
- Add search, opening trees and engine analysis
